# Reporting a vulnerability

There are no released application versions yet. The security requirements are in [docs/SECURITY-MODEL.md](docs/SECURITY-MODEL.md).

A verified private reporting contact and GitHub private vulnerability reporting must be configured before this repository is opened for public contributions or application releases. No support address is invented here. Until a private route exists, do not publish exploit details, credentials, customer data, or private files in issues.

Provide the affected revision, a minimal reproduction using synthetic data, impact, and the boundary crossed. Do not test against unrelated live systems or other people's accounts. Coordinated disclosure expectations and supported-release windows will be published before the first release.
