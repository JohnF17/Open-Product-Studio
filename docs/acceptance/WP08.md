# Guided workspace

The Windows development build opens a local project chooser inside the Electron shell. Blank starts with notes. Digital product opens format, brief, outline, manuscript and export steps. Video starts with a style and shows its required and optional tools before the brief. The remaining steps cover storyboarding, materials, a text preview, review, draft export and publication planning.

Next slides the current sheet left. Back slides it right. The incoming heading receives focus and the outgoing form is inert. Reduced motion changes the step immediately. The project list reopens a draft at its saved step.

The Windows walkthrough records both directions in the actual Electron window. The same test opened a recommendation in the composer, returned to the saved project and reopened it after restarting Electron. ## What this build persists

The expanded chooser adds Clipper, Replica and Day Trader authored drafts. Clipper can preview caption placement on a local still and save an edit plan. Replica exports an original behavior brief. Day Trader keeps a manual practice journal offline. The three guides share the existing draft storage and sheet navigation. Clipper and Replica can prepare writing requests for the composer. Day Trader has no agent dispatch or broker connection.

Clipper flags captions that exceed the preview frame and shows the saved text and look on Review. Replica previews the collaborator's brief before download. The user can include one permitted observation. A separately labelled private backup retains the source location and permission notes. Editing a selected composer excerpt requires selecting the revised text again.

The six-category capture exercised the renderer in an isolated Chromium content window at desktop and narrow widths. It checked save, return, resume and JSON export. The Clipper recording also shows audition, apply and undo for a caption look. [Screenshots and evidence](WP08/categories/README.md) · [Video](WP08/categories/entry-resume-edit.webm)

Working drafts live in the local Electron profile's IndexedDB, keyed by engine workspace and project ID. Saves check the previous revision in a single write transaction. When another window wins a write, the losing editor retains its text and offers an export. Download draft produces an editable JSON file. Each category can be started without setting up an AI provider.

The agent button saves the project and prepares a recommendation request in the native T3 composer. The user chooses the connection and model and reviews the request there. The built-in examples are labeled starters. Tool selection records a production plan. Media rendering, plugin installation, web research, native document delivery and social publication have separate release gates.
