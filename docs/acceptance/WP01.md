## Downstream packaging diagnostic

The pristine payload had 67 ordinary files, 21 prepared V8 cache blobs and one cache manifest. Studio's Windows cache generator always retains the CLI and server entry points and omits optional cache blobs smaller than 16 KiB. All module sources remain in the server ASAR. macOS and Linux retain the upstream selection behavior.

The changed generator ran in the packaged Electron executable against a separate copy of the pristine unpacked distribution. It produced nine usable cache entries. The original upstream validator accepted the resulting 77-file payload and 26 sidecar-native paths. A runtime probe confirmed all nine active blobs matched. This diagnostic validates cache generation and the unchanged payload gate. Studio-branded installer creation, installed launch and cold-start performance are separate qualification results.
