# WP02 working evidence

On November 19, the first Studio desktop change assigned different Electron profile directories to development and production: `open-product-studio-dev` and `open-product-studio`. Boot assigns both Chromium user data and session data before acquiring the single-instance lock. The fork removes T3's legacy profile key copy, local-storage reader and migration IPC. Ordinary first launch also skips the inherited CLI installation and PATH change.

Five focused suites exercised pre-ready initialization, profile selection, fixture boot, Clerk initialization and error handling. On Windows, 29 tests passed and the POSIX permission test was skipped. The tests used synthetic T3 sentinel profiles, an isolated environment and mocked external services. The source build and packaged binary documented under [WP01](WP01.md) are the pristine upstream baseline.

WP02 still owns the independent server state directory, OS application/CLI/protocol names, vault, account endpoints, telemetry, update feed and a complete Studio-branded install, restart and uninstall. Explicit user-invoked CLI settings actions also require their Studio namespace before release.
